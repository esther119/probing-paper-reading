What this paper is about

A large language model (LLaMA-2-13B) was never explicitly taught what is true or false. Yet Marks & Tegmark show that, inside the model, true and false statements are separated by a single straight line in activation space — and you can find it.

The paper does this in three moves: (1) pinpoint the slot inside the model that carries the truth judgment, (2) confirm it's the one that causally drives the output, and (3) recover the "truth direction" along which true and false statements split. The three lessons below mirror those three moves.

To get there, the paper relies on a small pipeline that turns each sentence into a single vector and then asks where that vector lives. Here's the whole pipeline at a glance — each step is what one of the lessons (or the underlying probe methods) will zoom into:

Lesson 1 — Where in the model does "truth" live?

Before we can do anything clever, we need to know which slot inside the model stores its judgment of a sentence as true or false.

When an LLM reads a sentence, it doesn't store its understanding in a single place. Every token (word or punctuation) gets its own hidden state — a vector of thousands of numbers — at every layer of the network. That's a lot of vectors per sentence. Which one carries the model's "is this true?" judgment?

The key fact: transformers are causal. A token at position i can only attend to tokens at positions ≤ i. So if you grab the hidden state at "Paris" in the middle of a sentence, it has no idea what comes after. Only the last token has read the whole thing.

Takeaway: The model's "summary" of the whole sentence lives over the end-of-sentence punctuation token. The period has seen all previous tokens (causal mask) and carries no word-meaning of its own, so its hidden state is a clean place to read off truth. That's what the paper uses: layer 15, period token for LLaMA-2-13B.

Lesson 2 — Proving it: the activation patching experiment

"The period summarizes truth" is a hypothesis. To prove it, the paper runs a clean experiment: surgically swap one hidden state from a true-sentence run into a false-sentence run, and watch what happens.

The setup

Two sentences that differ by one word:

  • pT: "The city of Toronto is in Canada." → model says TRUE
  • pF: "The city of Chicago is in Canada." → model says FALSE

The experiment:

  1. Run the model on pT and cache every hidden state (every position, every layer).
  2. Run the model on pF. At one chosen (layer, position), overwrite the activation with the cached value from the TRUE run.
  3. See if the model's prediction flips toward TRUE.

If swapping a particular slot can flip the answer, that slot is causally responsible for the truth judgment. 👉🏽 Click cells in the FALSE grid to try the swap.

Lesson 3 — Finding the truth direction

Now that we know where the model stores truth (a single hidden state vector per sentence), we can ask: what does the geometry of those vectors look like?

What's a "truth direction"?

Inside the model, every sentence becomes a vector — a point in a high-dimensional space (5120 numbers for LLaMA-2-13B). A direction in that space is just an arrow (a unit vector). You can project any point onto the arrow and get a single number: "how far along it does this sentence sit?"

A direction θt is a truth direction if projecting sentences onto it lines up with their truth value — true statements pile up on one side of zero, false on the other, with a clean gap.

Why this is surprising: the model wasn't trained to do this. Yet, internally, it apparently keeps a running tally of "is this claim true?" along a clean linear axis — and you can read it off with a single dot product. That's the "geometry of truth."

Three ways to find it

Given a labeled dataset of true/false activations, three different methods can recover θt:

  • LR — Logistic Regression. Fit a linear classifier. Maximum-margin separator. Sensitive to confounds — tilts away from the true direction when correlated features exist.
  • MM — Mass-Mean probing. The paper's contribution. Just take μ+ − μ−: the arrow from the center of the false cluster to the center of the true cluster. Optimization-free. Often more causally meaningful than LR.
  • CCS — Contrast-Consistent Search. Unsupervised. Uses pairs of (statement, negation) and finds a direction along which pair members separate. No labels needed, but brittle.

Experiments to try

  1. Set confound to 0. All three methods overlap with θt. The problem is trivial — no competing variance.
  2. Crank confound to 2.5, angle 30°. LR visibly tilts away from θt; MM stays glued to it. This is Fig. 4 of the paper.
  3. Drop contrast pair strength to 0.2. Negation no longer cleanly flips truth; CCS latches onto the wrong direction.
Takeaway: All three methods are searching for the same thing — the arrow along which labels differ. They disagree when the cloud has extra structure that's correlated with (but not equal to) truth. Mass-mean is the paper's recommendation: it ignores the cloud's shape and just connects the class means, which gives a more causally meaningful direction in real LLMs.

Putting it all together

You now know the pipeline:

  1. Pick the right slot — the hidden state over the end-of-sentence period, in a middle layer. That's the model's summary of the whole statement (Lesson 1).
  2. Confirm it's causal — activation patching shows that swapping this slot from a true-sentence run can flip a false-sentence prediction (Lesson 2).
  3. Find the truth direction — given a labeled dataset of these activations, methods like mass-mean recover a single arrow θt in activation space along which true and false sentences separate (Lesson 3).

What you can do once you have θt:

  • Detect when the model "believes" a statement — just project and check the sign.
  • Steer the model — add θt to its activations during a forward pass and watch its outputs shift toward truthful behavior. This is the causal validation in §6.

The fact that a single linear direction can be used to control the model is strong evidence that truth isn't tangled nonlinearly across the network — it's just an axis the model uses, and the geometry tools above let you find it.

Where to go next: The paper also shows that the truth direction generalizes across topically different datasets (cities, comparisons, negations) — and that as models get bigger, the direction becomes more universal. That's the "Geometry of Truth" thesis: scale produces increasingly abstract, shared linear representations of concepts like truth.
